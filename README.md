# ГІС Диспетчерська Система Регіональних Електромереж (v6.0)

ГІС Диспетчерська Система — це комплексна цифрова платформа для оперативного управління, моніторингу, технічного обслуговування та комерційного обліку електричних мереж АТ «Вінницяобленерго». Система забезпечує єдиний інформаційний простір для взаємодії диспетчерів, виїзних бригад, адміністраторів та менеджерів комерційного відділу.

### 🎯 Ключові можливості системи:
🗺️ Інтерактивна ГІС-картографія: Використання Folium для візуалізації об'єктів мережі (підстанції, опори, центри клієнтів), ліній ЛЕП та зон обслуговування з прив'язкою до реальних геокоординат та інтерактивними маркерами станів.

📱 Цифровий кабінет лінійної бригади: Автоматизований процес закриття наряд-допусків. Включає фіксацію геопозиції (GPS), фотозвіт "до/після" робіт, чек-листи техніки безпеки (ПУЕ) та транскрибацію голосових звітів.

🌡️ SmartGrid AI — Аналітика: Модуль предиктивної аналітики, що розраховує навантаження на мережу залежно від погодних умов (температурний діапазон -20°C…+40°C), виявляє аномалії та прогнозує критичні навантаження.

💰 CRM та Білінг: Дашборд для контролю рівня оплат, теплова карта заборгованостей по дільницях, реєстр боржників та вбудований калькулятор тарифних зон для споживачів (одно-, дво- та тризонні лічильники).

📋 Оперативне управління: Рольова модель доступу (Диспетчер, Адмін, Бригада, Менеджер), журнал подій (Audit Log), графік планового ТО та інструменти дистанційного керування обладнанням.


### 🛠️ Технічний стек:
Мова: Python 3.11+

Фреймворк: Streamlit (v1.35+)

Візуалізація даних: Pandas, Matplotlib

Картографія: Folium, streamlit-folium

Архітектура: Рольова модель доступу (RBAC), управління станом сесій (Session State), інтеграція зі структурою АТ «Вінницяобленерго».

Це рішення спрямоване на цифрову трансформацію енергетичних компаній, підвищення швидкості реакції на аварійні ситуації та оптимізацію роботи виїзних технічних бригад.
