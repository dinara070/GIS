### ГІС «Диспетчерська Система Регіональних Електромереж» (v6.0)

## Загальний огляд
Система являє собою інтегровану цифрову платформу для АТ «Вінницяобленерго», розроблену для автоматизації управління енергетичними активами, диспетчеризації виїзних бригад та ведення комерційного обліку. Проєкт забезпечує єдиний інтерфейс для оперативного моніторингу стану електромереж, прийому звернень споживачів та аналізу даних.

## Ключові функціональні можливості
- Інтерактивна ГІС-мапа: Реалізована на базі бібліотеки Folium, вона візуалізує об'єкти мережі (опори, підстанції, ЦОК) та лінії ЛЕП з урахуванням їх технічного стану. Користувачі можуть перемикати шари (ЛЕП, зони обслуговування) для аналізу обстановки в реальному часі.
- GIS Editor: Інструмент для швидкого оновлення топології мережі. Дозволяє адміністраторам додавати нові об'єкти безпосередньо на мапі, автоматизуючи введення координат та підв’язку до структурних одиниць (СО).
- SmartGrid AI та діагностика: Модуль аналізу напруги за ГОСТ 13109-97 / ДСТУ EN 50160. Система автоматично детектує аномалії (перенапругу/просадки), прогнозує навантаження залежно від погодних умов та надає рекомендації щодо обслуговування обладнання.
- Управління мобільними бригадами: Цифровий «кабінет бригади» з підтримкою GPS-геолокації, чек-листами безпеки (згідно з ПУЕ), можливістю додавання фотозвітів та транскрибації голосових звітів про виконані роботи.
- CRM та Білінг: Аналітичний блок для комерційного відділу. Включає теплову карту заборгованостей, реєстр боржників та універсальний калькулятор тарифів (одно-, дво- та тризонні лічильники), що автоматично розраховує вартість з урахуванням ПДВ та попередніх боргів.
- Центр сповіщень: Оперативна система Push-повідомлень та SMS для миттєвого інформування бригад про аварії чи зміну погодних умов.
- Ресурсний менеджмент: Контроль складських залишків із прив’язкою до конкретних структурних одиниць (СО). При реєстрації аварії система автоматично перевіряє наявність необхідних запчастин на складі відповідного району.

## Технологічний стек:
- Мова програмування: Python 3.11+.
- Frontend-фреймворк: Streamlit (версія 1.35+).
- Візуалізація та ГІС: Folium, streamlit-folium, Matplotlib.
- Обробка даних: Pandas, NumPy, JSON, IO.
- Архітектура: Рольова модель доступу (Admin, Dispatcher, Brigade, CRM) з інтеграцією аудиту дій (оперативний журнал подій).

## Переваги для бізнесу
- Оперативність: Скорочення часу на передачу наряд-допусків та зворотного зв'язку від бригад.
- Проактивність: Можливість виявлення перевантажень мережі та дефектів обладнання до настання аварійної ситуації (завдяки AI-модулю).
- Контроль: Повна прозорість складських запасів та рівня оплати споживачів.
- Безпека: Цифрові чек-листи мінімізують ризик помилок при проведенні робіт на енергооб'єктах.

Цей проєкт є гнучким рішенням, готовим до масштабування та інтеграції з реальними SCADA-системами через API.
